# 图案转浅浮雕

把班徽、校徽、Logo 或插画做成有真实凸起的浅浮雕，也可以先出效果图确认层次，或按用途制作带贴图的彩模、掐丝珐琅式填砂隔断和拓竹分色部件。

- [工具链与运行步骤](TOOLCHAIN.md) 说明复现班徽白模需要安装什么，以及哪些工具按需使用。
- [SKILL.md](SKILL.md) 按交付物选择浅浮雕、透光浮雕、填砂隔断或拓竹分色流程。
- [prepare_height.py](scripts/prepare_height.py) 将已确认高低关系的灰度图去噪和平滑，输出浮点高度数据和 16 位 PNG。

在支持 Skills 的工具中加载此目录，提供原图并说明想要效果图、白模还是 STL。
